课程 0007 · 动手第①步：PHP 单轮 LLM 调用

Agent Foundations · 动手阶段第 1 课 · 预计 12 分钟

概念层结束了。从这节课开始，你不再只是"知道 Agent 是什么"——你要亲手跑出第一条代码链路。第①步的目标极小：用你最熟的 PHP，发一条消息给 LLM，收到一句回复。就这一件事，跑通就是胜利。

验收标准（来自 0006 路线图）：能跑通一次 model("你好") → "你好！"。命令行能跑即可。用 curl 或脚本，看到回复就行。

1. 准备工作（5 分钟）

前提你有一个可用的 LLM API Key（OpenAI / DeepSeek / 其他兼容 OpenAI 格式的均可）。本课用 DeepSeek 做示例（便宜、国内直连），但你换成 OpenAI 只需改 URL 和 key。
PHP 版本≥ 8.0（用到了 named arguments 和 match 表达式，但实际代码兼容 7.4+）。
依赖纯 PHP 内置函数（curl_* / file_get_contents / json_encode），零第三方包。你可以之后换成 Guzzle，但第一步不想让你被 composer 分心。

2. 最简代码（复制即用）

把下面这个文件保存为 step1.php，填上你的 API key，在终端跑 php step1.php：

// step1.php — 最简单轮 LLM 调用（PHP 原生，零依赖）
<?php

$API_KEY = 'sk-your-key-here';          // ① 换成你的 key
$API_URL = 'https://api.deepseek.com/v1/chat/completions';
$MODEL   = 'deepseek-chat';                   // 用 OpenAI 的话改 model + URL

$payload = [
    'model'    => $MODEL,
    'messages' => [['role' => 'user', 'content' => '你好，请用一句话介绍你自己']],
    'max_tokens' => 128,
];

$ch = curl_init($API_URL);
curl_setopt_array($ch, [
    CURLOPT_POST           => true,
    CURLOPT_HTTPHEADER     => [
        'Content-Type: application/json',
        'Authorization: Bearer ' . $API_KEY,
    ],
    CURLOPT_POSTFIELDS     => json_encode($payload),
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_TIMEOUT        => 30,
]);

$body   = curl_exec($ch);
$status = curl_getinfo($ch, CURLINFO_HTTP_CODE);
curl_close($ch);

if ($status !== 200) {
    die("API 返回 HTTP $status\n" . $body);
}

$data = json_decode($body, true);
$reply = $data['choices'][0]['message']['content'];
echo "模型回复：" . $reply . "\n";

跑出来大概是：

模型回复：你好！我是 DeepSeek，一个由深度求索公司创造的 AI 助手。

3. 逐行讲解（你不需要背，但需要"认得出"）

$payload这是发给 LLM 的 JSON body。四个核心字段：model（用哪个模型）、messages（对话数组，目前只有一条 user）、max_tokens（回复最长多少 token，防账单失控）。
curlPHP 原生的 HTTP 客户端。3 步套路：curl_init → curl_setopt_array（设 header/body/timeout）→ curl_exec。你后端早就会了，这里只是把 JSON 用 POST 发到 LLM 的 API endpoint。
$datajson_decode(..., true) 把返回的 JSON 转成 PHP 关联数组。OpenAI 兼容 API 的回复结构固定：choices[0].message.content 就是模型说的文本。
PHP 后端直觉：这和你平时调的任何一个 REST API 一模一样——POST JSON → 读 response JSON → 取字段。区别只在于：这个 API 的"返回值"不是数据库记录，是一段模型生成的文本。本质上，LLM 就是一个"输入文本、输出文本"的函数。

4. 如果你用的是 OpenAI（而非 DeepSeek）

改两行即可：

$API_URL = 'https://api.openai.com/v1/chat/completions';
$MODEL   = 'gpt-4o-mini';  // 便宜够用

其余代码一模一样——OpenAI / DeepSeek / 任何兼容 OpenAI 格式的提供商，都是同一套 chat/completions 协议。

5. 验收清单（你真的跑通了才算）

  • 在终端跑 php step1.php，没有报错
  • 看到了模型回复的一句话（不是乱码、不是空）
  • 你能把 '你好，请用一句话介绍你自己' 改成任意文本，再跑一次，看到不同回复
  • 你知道如何换模型 / 换 API provider
