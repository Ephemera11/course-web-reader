课程 0009 · 动手第③步：PHP 接第一个工具 get_time()

Agent Foundations · 动手阶段第 3 课 · 预计 18 分钟

上节课 Agent 能自己跑多轮，但只会"想"不会"做"。这节课给它接上一个真实的 PHP 函数——get_time()。模型说"我需要查时间"→ 你的代码执行 → 把结果喂回去。这就是第 3 课讲的 Tool Calling 在代码里第一次落地。

验收标准：定义 get_time 工具，Agent 被问"现在几点"时能正确调用并回复时间。

1. 工具定义 + 执行器（关键代码）

在 step2.php 基础上加两个数组——工具定义（告诉模型有什么工具）+ 工具映射（PHP 函数名→实际 callable）：

// 工具定义（告诉模型：你有一个叫 get_time 的工具）
$tools = [[
    'name' => 'get_time',
    'description' => '获取当前日期和时间。当你需要告诉用户现在几点时调用此工具。不需要参数。',
    'parameters' => [
        'type' => 'object',
        'properties' => new stdClass,  // 无参数
        'required' => [],
    ],
]];

// 工具执行器：工具名 → PHP 函数
$executors = [
    'get_time' => function() {
        return date('Y-m-d H:i:s');
    },
];

2. 循环里怎么接：调 LLM → 看它要啥工具 → 执行 → 喂回

for ($i = 0; $i < $MAX_ITER; $i++) {
    echo "\n═══ 第 " . ($i + 1) . " 轮 ═══\n";

    $payload = ['model'=>$MODEL, 'messages'=>$messages, 'max_tokens'=>256];
    if (!empty($tools)) $payload['tools'] = $tools;  // 告诉模型有哪些工具

    // curl 调用（同 step2）
    $ch = curl_init($API_URL);
    curl_setopt_array($ch, [
        CURLOPT_POST=>true, CURLOPT_HTTPHEADER=>['Content-Type: application/json','Authorization: Bearer '.$API_KEY],
        CURLOPT_POSTFIELDS=>json_encode($payload), CURLOPT_RETURNTRANSFER=>true, CURLOPT_TIMEOUT=>30]);
    $body=curl_exec($ch);curl_close($ch);
    $data=json_decode($body,true);
    $msg=$data['choices'][0]['message'];

    // 检查模型是否要调工具
    if (!empty($msg['tool_calls'])) {
        $messages[] = $msg;  // 保留模型的 tool_calls 消息
        foreach ($msg['tool_calls'] as $tc) {
            $name = $tc['function']['name'];
            $args = json_decode($tc['function']['arguments'], true) ?: [];
            echo "🔧 模型要调工具: $name\n";
            $result = $executors[$name](...$args);  // 执行你的 PHP 函数
            $messages[] = ['role'=>'tool', 'tool_call_id'=>$tc['id'], 'content'=>json_encode($result)];
            echo "✅ 执行结果: $result\n";
        }
        continue;  // 把 tool_result 喂回 LLM，进入下一轮
    }

    // 普通文本回复
    $reply = $msg['content'] ?? '';
    echo "模型：" . $reply . "\n";
    $messages[] = ['role'=>'assistant', 'content'=>$reply];
    if (str_contains($reply, 'FINISH')) break;
}

3. 一次完整往返（问时间 → 调工具 → 回复）

轮 1Agent 发送 user msg："现在几点" + tools 定义 → LLM 返回 tool_calls: [{function: {name: "get_time"}}]
执行PHP 捕获 tool_calls → $executors['get_time']() → 返回 "2026-07-29 15:42:01"
轮 2把 tool_result 追加到 messages → 再调 LLM → LLM 看到时间 → 回复 "现在是 2026 年 7 月 29 日 15:42"

4. 完整 step3.php 要点

在 step2.php 基础上 只加 3 处：① $tools 工具定义数组（放在循环外）；② $executors 函数映射；③ 循环里 if (!empty($msg['tool_calls'])) { ... } 分支。

PHP 工程师直觉：这和你做过的 策略模式 / 路由分发一模一样——模型返回一个函数名 + 参数，你 `call_user_func` 执行，结果写回上下文。区别只是：调用方不是代码里的 if/switch，是 LLM 在循环里自己决定的。
