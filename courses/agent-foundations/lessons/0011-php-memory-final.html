课程 0011 · 动手第⑤步：PHP 加记忆 + 收束

Agent Foundations · 最后一课 · 预计 15 分钟

Agent 能循环能调工具了，但关掉进程再开——它失忆了。最后一课把 messages 落地成文件，Agent 告别"金鱼记忆"，变成能跨会话记住你的真正助手。这也是 11 课路线的终点。

验收标准：先问"我叫张三"，关掉进程重启，问"我叫什么"，Agent 答"张三"。

1. 记忆层：messages.json

在 step4.php 基础上加一个 JSON 文件，进程启动时加载历史、退出时持久化：

// 记忆文件路径
$MEMORY_FILE = __DIR__ . '/memory.json';

// 启动时加载已有记忆
if (file_exists($MEMORY_FILE)) {
    $messages = json_decode(file_get_contents($MEMORY_FILE), true);
    echo "📂 已加载 " . count($messages) . " 条历史消息\n";
} else {
    // 首次：加一条 system 提示词
    $messages = [['role'=>'system', 'content'=>'你是一个有帮助的助手。回答简洁，需要工具就调用。回答完说 FINISH。']];
}

// 如果提供了命令行参数，作为本轮用户输入
if ($argc > 1) {
    $messages[] = ['role'=>'user', 'content'=>$argv[1]];
}

// ...（循环、工具调用等与 step4 完全相同）...

// 退出前持久化
file_put_contents($MEMORY_FILE, json_encode($messages, JSON_UNESCAPED_UNICODE|JSON_PRETTY_PRINT));
echo "💾 已保存 " . count($messages) . " 条消息到 memory.json\n";

2. 用法演示

# 第一次对话
php step5.php "我叫张三"
→ Agent: 好的张三，我记住了。FINISH
→ 💾 已保存 4 条消息到 memory.json

# 第二次对话（关掉重开）
php step5.php "我叫什么名字"
→ 📂 已加载 4 条历史消息
→ Agent: 你叫张三。FINISH

3. 你刚刚手搓了一个完整的 Agent 系统

单轮调用POST JSON → 取回复 → 结束
循环骨架for + messages 历史 + FINISH 停止协议
工具调用$tools 定义 + $executors 映射 + tool_calls 分支
工具选路双工具并行，模型自己决定调哪个、传什么参
持久记忆memory.json 加载/保存，跨会话保持上下文
✅ 对照 0006 路线图，5 步全部跑通。你从零行代码出发，用 PHP 原生 curl 搭出了一个 Agent = LLM + while 循环 + 工具执行器 + 文件记忆。

4. 从这出发，你可以往哪些方向深挖（自愿）

安全工具执行器加权限控制（白名单函数、参数校验、超时/重试）。
多用户每人一个 memory_{$userId}.json，Agent 记住不同人的上下文。
工具发现把 $tools 数组做成可插拔——加一个新工具只要新建一个 PHP 文件 + 注册一条。
多 Agent一个编排者 Agent + 多个工作者 Agent，各拿不同工具集。
Web 化把 CLI 脚本包成 HTTP API，前端聊天界面 → POST /chat → 返回流式回复。
