课程 0005 · 插件：Vite 的真正扩展点

Vite 从零入门 · 第 5 课 · 预计 13 分钟

Vite 本身很克制，大部分能力靠插件补。Vue/React 支持、自动导入、压缩、PWA——全都是插件。这一课你搞懂插件是什么、怎么装、常见插件有哪些，以后遇到需求先想「有没有现成插件」而不是自己造轮子。

本节目标：理解插件解决了什么问题、能在哪些时机介入构建、以及会用 2-3 个最常用的官方/社区插件。

1. 插件解决什么问题

Vite 核心只做「开发服务器 + Rollup 打包」两件通用的事。但真实项目有千百种需求：支持 Vue 单文件组件、把图片转 base64、生成 sitemap……这些不可能塞进核心。插件就是在特定时机注入自定义逻辑的钩子。

2. 插件怎么工作（钩子模型）

Vite 插件复用 Rollup 的钩子体系。简化理解：构建过程中有一连串「时刻」，插件可以在某个时刻插一脚：

config读取/修改配置时
resolveId解析模块路径时（别名就是在这干预）
transform每个源码文件被转换时（改代码、注入内容）
buildEnd打包结束时

3. 用插件：三部曲

// 1) 安装
// npm i -D @vitejs/plugin-vue

// 2) 在 vite.config.js 引入
import vue from '@vitejs/plugin-vue';

// 3) 加到 plugins 数组
export default defineConfig({
  plugins: [vue()],
});
绝大多数需求都已有插件：Vue→@vitejs/plugin-vue、React→@vitejs/plugin-react、自动导入→unplugin-auto-import、压缩→vite-plugin-compression。先搜再写。

4. 写个极简插件感受一下

export default defineConfig({
  plugins: [{
    name: 'hello',
    transform(code, id) {
      // 对每个 .js 文件，在末尾加一行注释
      if (id.endsWith('.js')) {
        return code + '\n// built by my plugin';
      }
    },
  }],
});

这就是一个合法插件：一个带 name 和钩子的对象。看懂这个，你就理解了所有插件的本质。
