课程 0011 · 综合实战：从零搭一个真实小项目

Vite 从零入门 · 第 11 课（收官）· 预计 18 分钟

前面 10 课拆开了讲，这一课把它们串起来：从空目录开始，搭一个「待办列表」小应用，用到配置、别名、环境变量、模块化、构建部署全流程。做完你就拥有独立用 Vite 开工的能力。

本节目标：跟着走完一个最小完整项目，建立「从 init 到 deploy」的全局节奏；理解每一步在整体中的位置。

1. 初始化

# 用官方脚手架（vanilla 模板，无框架）
npm create vite@latest todo-app -- --template vanilla
cd todo-app
npm install

2. 加配置与别名

新建 vite.config.js，配 @ 指向 src：

import { defineConfig } from 'vite';
import { fileURLToPath, URL } from 'node:url';
export default defineConfig({
  resolve: { alias: { '@': fileURLToPath(new URL('./src', import.meta.url)) } },
});

3. 分层写代码

src/main.js入口：挂载事件、渲染列表
src/store.js数据层：增删改待办（用 @/store 引入）
src/style.css样式，被 main.js import
// src/store.js
let todos = [];
export function addTodo(text) { todos.push({ text, done: false }); }
export function getTodos() { return todos; }
// src/main.js
import { addTodo, getTodos } from '@/store';
import './style.css';
// 绑定按钮、渲染列表……

4. 区分环境的 API 地址

# .env.development
VITE_API_BASE=http://localhost:3000
# .env.production
VITE_API_BASE=https://api.mysite.com

代码里统一用 import.meta.env.VITE_API_BASE，部署时无需改代码。

5. 构建与部署

npm run build      # 产出 dist/
npm run preview     # 本地预览产物

把 dist/ 传到 Vercel（连 Git 自动部署）或对象存储即可上线。至此，一个完整闭环走完。

你已掌握的能力：① 理解 Vite 的快来自原生 ESM；② 跑起开发服务器与 HMR；③ 配 vite.config 与别名；④ 用插件扩展；⑤ 管环境变量与 mode；⑥ 多页/库模式；⑦ 处理 CSS 与资源；⑧ 做构建优化；⑨ 部署到任意静态平台；⑩ 串成完整项目。
