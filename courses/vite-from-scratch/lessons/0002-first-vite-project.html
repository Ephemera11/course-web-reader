课程 0002 · 5 分钟跑起你的第一个 Vite 项目

Vite 从零入门 · 第 2 课 · 预计 15 分钟

上节课建立了心智模型，这节课真刀真枪跑起来。你会用 npm 初始化一个 Vite 项目、启动开发服务器、改一行代码看热更新、最后打包出静态产物。全程复制命令即可。

验收标准：本地能 `npm run dev` 启动开发服务器，浏览器打开看到页面；改代码后页面即时更新；`npm run build` 产出 `dist/` 静态文件。

1. 前置：装好 Node.js

Vite 基于 Node.js。先确认已安装（需 Node 18+）：

node -v
# 输出版本号，如 v20.11.0 即可。没装就去 nodejs.org 下 LTS 版。

你熟悉 PHP，可以把 Node 类比成 PHP 的运行环境——没有它 Vite 跑不起来。包管理器 npm 随 Node 自带，类比 Composer。

2. 三种起步方式（任选其一）

方式 A（推荐）官方脚手架，一行命令生成完整模板npm create vite@latest my-app -- --template vanilla
方式 B手写最小项目（更适合理解原理）建目录 + package.json + 手写 index.html
方式 C用框架模板（Vue/React）--template vue 或 --template react

这节课用 方式 B 手写最小项目，因为你能看清每个文件的作用。理解了 B，A 和 C 自然就懂。

3. 手写最小 Vite 项目（4 个文件）

package.json声明项目元信息 + 依赖 vite + 两个脚本（dev / build）
index.html入口 HTML，必须放在根目录，Vite 从它开始解析模块
main.js你的 JS 源码，用 ESM import/export，被 index.html 引用
style.css样式文件，被 main.js 用 import './style.css' 引入
// package.json
{
  "name": "my-vite-app",
  "private": true,
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "preview": "vite preview"
  },
  "devDependencies": { "vite": "^5.0.0" }
}
<!-- index.html（放根目录）-->
<!DOCTYPE html>
<html><head><meta charset="utf-8"></head>
<body>
  <h1 id="app"></h1>
  <script type="module" src="/main.js"></script>
</body></html>
// main.js
import './style.css';
document.querySelector('#app').textContent = 'Hello Vite!';
/* style.css */
#app { color: #7c2d12; font-family: sans-serif; }

4. 跑起来

# 安装依赖（类比 composer install）
npm install

# 启动开发服务器
npm run dev

终端会输出类似：➜ Local: http://localhost:5173/。打开这个地址，看到 Hello Vite! 就成功了。

关键体验：热更新（HMR）。把 main.js 里的文字改成 'Hello Vite 2!' 保存——浏览器不用刷新就自动变了。这就是第 1 课说的"改代码即时生效"。

5. 生产打包

# 打包成静态文件
npm run build

# 本地预览打包结果（模拟生产环境）
npm run preview

打包后生成 dist/ 目录——里面是优化过的 HTML/JS/CSS。把这整个目录丢到 nginx、Vercel、OSS 任意静态服务器就能上线。你熟悉的 phpstudy 也能直接托管 dist/。
