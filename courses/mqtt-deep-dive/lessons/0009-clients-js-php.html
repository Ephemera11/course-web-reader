课程 0009 · 客户端实战：MQTT.js 与 PHP

MQTT 深入 · 第 9 课 · 预计 16 分钟

命令行只能测试，真实项目要用代码。这一课写两个客户端：Node 的 MQTT.js 和 PHP 的 php-mqtt——覆盖你熟悉的两条技术栈，连上第 8 课装的 Mosquitto 跑通「发布/订阅」。

本节目标：能用 MQTT.js 和 PHP 各写一个能连 Broker、订阅、发布的客户端。

1. Node：MQTT.js 发布与订阅

// 安装：npm i mqtt
const mqtt = require('mqtt');
const client = mqtt.connect('mqtt://localhost:1883');

client.on('connect', () => {
  client.subscribe('sensor/temp');
  client.publish('sensor/temp', '23.5');
});

client.on('message', (topic, payload) => {
  console.log(topic, payload.toString());
});

跑起来你会看到自己发的消息又收回来——因为你也订阅了。这正好验证了「发给自己订阅的 Topic」是允许的。

2. MQTT.js 连接选项

clientId默认自动生成；Clean Session=false 时一定要固定
username/password安全课用，连接认证
will遗嘱对象 {topic, payload}
keepalive心跳秒数，默认 60
cleanClean Session 开关，默认 true

3. PHP：php-mqtt 发布

// 安装：composer require php-mqtt/client
<?php
use PhpMqtt\Client\MqttClient;
use PhpMqtt\Client\ConnectionSettings;

$settings = (new ConnectionSettings())
    ->setUsername('')
    ->setPassword('');
$mqtt = new MqttClient('localhost', 1883, 'php-publisher');
$mqtt->connect($settings);
$mqtt->publish('sensor/temp', '23.5', 1);
$mqtt->disconnect();

PHP 发布是同步的：连接 → publish → disconnect。适合「事件触发上报」场景（比如收到 HTTP 请求后转发到 MQTT）。

4. PHP：订阅（常驻进程）

<?php
$mqtt = new MqttClient('localhost', 1883, 'php-subscriber');
$mqtt->connect($settings);
$mqtt->subscribe('sensor/#', function ($topic, $message) {
    echo "收到 [{$topic}] {$message}\n";
}, 1);
$mqtt->loopForever();  // 常驻监听，命令行/supervisor 跑

5. 选型速查

MQTT.jsNode 生态，事件驱动，适合实时服务mqtt://localhost:1883
php-mqttPHP 同步调用，适合 Web 触发上报composer require php-mqtt/client
命令行调试与测试最方便mosquitto_pub/sub
