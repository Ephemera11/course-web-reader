课程 0008 · 动手：搭建 Mosquitto Broker

MQTT 深入 · 第 8 课 · 预计 15 分钟

前 7 课全是理论，这一课落地：装 Mosquitto（最流行的开源 Broker），用命令行订阅/发布，亲眼看到消息流转。装好后你就有自己的本地 MQTT 服务器了。

验收标准：能在本机启动 mosquitto、用 mosquitto_sub 订阅、用 mosquitto_pub 发布、在订阅端看到消息。

1. 安装 Mosquitto

# Windows（choco 或直接装 exe）
choco install mosquitto

# macOS
brew install mosquitto

# Ubuntu/Debian
sudo apt install mosquitto mosquitto-clients

Debian 系装完 mosquitto 服务可能自动启动了，测试时建议先停掉用前台跑：sudo systemctl stop mosquitto。

2. 启动 Broker（前台）

# 默认端口 1883，-v 显示详细日志
mosquitto -v

看到 Opening ipv4 listen socket on port 1883 就成功了。

3. 开两个终端：订阅 + 发布

# 终端 1：订阅（保持运行）
mosquitto_sub -t 'test/topic' -v

# 终端 2：发布
mosquitto_pub -t 'test/topic' -m 'Hello MQTT'

终端 1 立刻打印 test/topic Hello MQTT。恭喜——第一条 MQTT 消息通了。

体验一下通配符：订阅端改成 mosquitto_sub -t 'test/#' -v，然后发布到 test/a、test/b/c——全都收得到。这就是 0003 课讲的 # 多层匹配。

4. 常用参数速查

-tTopic
-m消息内容（pub）
-v订阅时显示 Topic（sub）；Broker 显示详细日志
-h / -pBroker 地址 / 端口（默认 localhost:1883）
-u / -P用户名 / 密码（安全课用）
-qQoS 等级（默认 0）
-r发布保留消息（pub）

5. 验证 QoS 与保留消息

# QoS 2 发布
mosquitto_pub -t 'test/qos' -m 'important' -q 2

# 保留消息：发布 -r，然后新开订阅端立刻能收到
mosquitto_pub -t 'device/status' -m 'online' -r
mosquitto_sub -t 'device/status' -v   # 立刻打印 online，无需等新消息
